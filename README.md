# Raytheon Interview Prep

A directory for interview prep materials and small projects (e.g. SOC-style tools, log analysis).

## Contents

### Log Analyzer
A quick Python tool that scans system logs and counts failed login attempts.

- **Overview:** Reads a local log file and prints how many lines contain the word **"Failed"**.
- **How to run:** `python3 log_analyzer.py`
- **Example output:** `12 failed logins`
- **Tech:** Python • macOS Terminal • VS Code • Git
