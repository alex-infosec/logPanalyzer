# INC001 — Incorrect debug mode logging

**ServiceNow INC001**  
**Priority:** Medium  
**Assignment:** IT Intern — Systems  
**Status:** Open  
**System:** IATS — Asset Sync Pipeline

---

## Description

Asset sync service (IATS pipeline) is logging "Debug mode enabled" when config has `mode=normal`. Logs should only show "Debug mode enabled" when `mode=debug`. Ticket owner reports misleading logs during troubleshooting.

## Steps to Reproduce

1. Ensure `mode=normal` in `config/sync.conf`
2. Run: `./bin/asset_sync < /dev/null`
3. Observe logs

## Expected Behavior

- When `mode=normal`: log shows "Normal mode"
- When `mode=debug`: log shows "Debug mode enabled"

## Actual Behavior

Logs show "Debug mode enabled" for normal mode. Conditional logic appears inverted in `src/asset_sync.c`.

## Log Excerpt

```
[INFO] Config loaded: batch=10 timeout=30 mode=normal
[INFO] Debug mode enabled
```

## Resolution

Fix the conditional in `src/asset_sync.c` so the log message matches the config. Rebuild, validate logs, confirm with ticket owner.
