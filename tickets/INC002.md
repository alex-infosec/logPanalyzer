# INC002 — Parse failure message not actionable

**ServiceNow INC002**  
**Priority:** Medium  
**Assignment:** IT Intern — Systems  
**Status:** Open  
**System:** IATS — Asset Sync Pipeline

---

## Description

When asset_sync fails to parse an input line, it logs "Failed to parse asset" with no context. Support cannot debug issues without seeing the problematic input. Ticket owner reports inability to trace bad data from upstream.

## Steps to Reproduce

1. Run asset_sync with malformed input (no second comma — parse will fail):
   ```bash
   echo "ASSET,ID123" | ./bin/asset_sync
   ```
2. Observe logs

## Expected Behavior

Log should include the input line (or a sanitized excerpt) so we can identify bad data and trace back to source.

## Actual Behavior

```
Failed to parse asset
```

No input context. Improve the log message in `src/asset_sync.c` where parse fails to include the offending line (truncate if long).

## Resolution

Add the problematic input to the parse-failure log. Rebuild, validate, confirm with ticket owner.
