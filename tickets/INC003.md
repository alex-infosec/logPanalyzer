# INC003 — Config mismatch causes cryptic failure

**ServiceNow INC003**  
**Priority:** High  
**Assignment:** IT Intern — Systems  
**Status:** Open  
**System:** IATS — Asset Sync Pipeline

---

## Description

A deployment used a config with `batch_size=0`. The service exits with "Invalid batch_size" but operators initially thought it was a code bug. Root cause: **configuration mismatch** between environments, not a logic defect.

## Steps to Reproduce

1. Run: `./bin/asset_sync config/sync_bad.conf < /dev/null`
2. Observe: service exits with ERROR

## Expected Behavior

- Service should handle invalid `batch_size` safely (use default, e.g. 10)
- Log a **warning** so the issue is visible next time
- Service continues running

## Actual Behavior

Service exits with "ERROR: Invalid batch_size 0". Operators assumed code bug until config was reviewed.

## Resolution

1. Update `src/asset_sync.c` to validate config at startup
2. Use safe default when `batch_size` is invalid
3. Add `WARN:` log so config mismatch is obvious in logs
4. Confirm with ticket owner — logs show normal behavior after fix
